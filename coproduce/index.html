sam.toys · co-produce

An AI co-producer
that lives inside Ableton Live.

able-coproduce is an MCP server that lets Claude drive your Ableton session — build tracks, write clips, fire scenes, load instruments, edit automation, warp, and lay down fat basslines — by talking to Live through a Remote Script over a loopback socket. Clean sessions, sharp edges.

What it can do

Tracks & scenes
Create, route, arm, group; fire and capture scenes.
Clips & notes
MIDI + audio clips, loop/warp markers, velocity, probability.
Devices & browser
Browse the full tree, load by URI, read/write parameters.
Automation & warp
Write envelopes for any parameter; warp modes and segment BPM.
Groove
Groove pool, apply and commit groove to clips.
Generative helpers
Chord, scale and pattern utilities on top of the raw note API.

What it doesn't do (yet)

  • Only runs while Ableton is open with the AbletonMCP Remote Script loaded — nothing works headless or without Live.
  • Some tools are Live-version gated — creating audio clips needs Live 12; extended note fields (probability, release velocity) need Live 11+.
  • macOS & Windows only — no Linux, because Ableton Live doesn't run there.
  • Local & loopback-only by design — no remote/LAN control, no REST bridge, no Max for Live device.
  • Audio import is sandboxed to your ~/Music folder — it won't load files from anywhere else.

Get producing

  1. Install the server: uv tool install git+https://github.com/fnaticsam/able-coproduce
    Python 3.11+, macOS 13+ / Windows 10+. Ableton Live 11.3+ or 12.x.
  2. Install the Remote Script into Ableton's User Library/Remote Scripts/AbletonMCP, then in Live pick AbletonMCP as a Control Surface (Preferences → Link/Tempo/MIDI). Inputs/Outputs = None.
    You'll see AbletonMCP: ready in Live's status bar.
  3. Point your MCP client at it — { "command": "uvx", "args": ["able-coproduce"] } — and start asking for basslines.

Everything runs locally: the MCP transport plus the Remote Script's loopback socket, nothing else. A fork of ahujasid/ableton-mcp and jpoindexter/ableton-mcp, with the history/undo subsystem from ableton-copilot-mcp — merged, hardened, and de-risked.
