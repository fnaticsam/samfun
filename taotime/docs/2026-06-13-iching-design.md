# The Book of Changes — I Ching integration (design)

Date: 2026-06-13 · Status: built, in review

## What & why
Add the I Ching to the taotime Tao Te Ching site. The site's central interaction
(press-hold → water pours → a verse is revealed by chance) is already a divination
ritual, so an I Ching "cast a hexagram" feature is the most native possible extension.

Honest framing (load-bearing): the I Ching is NOT a Taoist scripture — its core
predates Laozi; both Taoism and Confucianism drew on it. It shares the Tao Te Ching's
grammar (yin/yang, change, reversal), so it's presented as the older sibling the Tao
grew up beside, and each hexagram links to the verse it most echoes.

## Decisions (user-approved)
- Scope: full caster ritual + verse links (not teaching-only / not light companion).
- Text: all 64 readings written FRESH in the site's living voice (not Legge quotes).

## Build
- New hash-page `#iching` (sidebar "Start Here" group, glyph 易). Primer + bagua
  illustration + caster + reading.
- Caster reuses the water-drop vessel: one press commits the cast; six lines pour in
  bottom-to-top (three-coin odds: 6=old yin, 7=young yang, 8=young yin, 9=old yang;
  6/9 = changing). Lines drawn as vermilion CSS bars (NOT Unicode hexagram glyphs).
- Reading laid out like the verse dives: hexagram card + judgment/image/reflection;
  changing lines → "Lines in motion" + the transformed second hexagram (clickable);
  "the verse it echoes →" deep-links to the resonant chapter; cast again / open menu.
- Data: HEXAGRAMS (64), structure authored + checksum-verified offline (all 64 distinct,
  every 6-bit pattern present, anchors correct); readings generated by an 8-batch
  workflow then a scholar pass refined 5 chapter mappings. Agents' line-patterns matched
  the authoritative data 64/64.
